
# Mini Sleep Lab
A simulated sleep-EEG analysis, built while learning Python for neuroscience.
## Aim
A sample project to learn basics of numpy,panda,matplotlib and get familiar with how EEG dataset and sleep related terms.
## What it does
- Simulates 30-second EEG epochs for awake, light and deep sleep
- Finds frequencies with the FFT and extracts delta, theta and alpha band power
- Summarises the results in a pandas DataFrame and plots them
- Classifies the stage with a simple rule (100% accuracy on simulated data)
